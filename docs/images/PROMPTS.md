# Image prompts

The logo and cartoons in this folder are hand-written SVG, so they're crisp at any size and easy to edit. To make
painted variants (for slides or a social preview) with an image model, use these prompts with the same style suffix:

Style suffix: *Flat vector cartoon illustration, friendly and playful, clean thick outlines, limited palette of deep navy
(#1B2A4A), teal (#14B8A6), warm amber (#F59E0B) and off-white (#FAF7F0), soft shadows, plain off-white background, no text.*

| File | Prompt |
|---|---|
| hero | A friendly retro mainframe cabinet with a smiling green-screen face and tape reels hands a glowing blueprint scroll to a cheerful small robot analyst holding a magnifying glass; the robot carries neat stacked documents over an arched bridge to a modern laptop showing an atom icon, a leaf and a database cylinder. |
| analyze | A small robot detective in a deerstalker hat studies a giant green-on-black terminal screen and a stack of punch cards, pinning colored strings from code lines to sticky notes on a corkboard. |
| document | A robot librarian arranges three document stacks of increasing thickness, each with a round version stamp and ribbon; colored threads connect pages across stacks; older versions sit in an archive box. |
| migrate | Tiny construction robots in hard hats dismantle an old mainframe block by block and rebuild it as an atom-shaped front-end block, a leaf-shaped service block and a cylinder database block, connected by a conveyor belt. |
| assess | A robot points at a clipboard matrix with rows of green, amber and grey status dots in three columns, with a speech bubble asking for evidence. |
