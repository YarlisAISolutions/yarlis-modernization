# AGENTS.md

Instructions for AI coding agents (GitHub Copilot, Claude Code, Codex, Cursor and others) working in this repository.

## Skills

Agent Skills live in `.claude/skills/`. GitHub Copilot, Copilot CLI, the Copilot cloud agent and Claude Code all load them from there:
- `legacy-code-analysis`: analyze existing code into `docs/analysis/` (`scripts/inventory.py scan|slice|domains`).
- `requirements-docs`: BRD/FRD/SRD/RTM/gap reports per feature (`scripts/docver.py`).
- `mainframe-modernization`: the legacy → React + Spring Boot + DB2 mapping (`scripts/mapgen.py`).

Use them for all requirements and analysis work. The scripts need only Python 3.9+. The same scripts are available as
`l2m analyze …`, `l2m map …` and `l2m docs …` when the `@l2m/cli` npm package is installed; both forms are equivalent.

## Requirements layout and rules

- One document set per feature: `docs/requirements/<module>/<feature>/` (kebab-case), scaffolded with
  `python3 .claude/skills/requirements-docs/scripts/docver.py new-feature --module <m> --feature <f>`.
- `docs/requirements/PROJECT-CONTEXT.md` holds project facts. `docs/requirements/INDEX.md` is generated by `docver.py index`.
- Keep the template sections. Never invent facts (write Unknown, or TBD with the decision and owner). Every requirement states its Basis.
- Evidence is a link to source lines (`path:line` + `docver.py linkify`), never pasted code.
- Bump a document's version before editing it (`docver.py bump`). Finish with `linkify`, `trace --inject`, `validate` and `index`.
- CI: `docver.py check docs/requirements` and `docver.py bumpcheck --base origin/<base>` must pass.

## Commits and PRs

Conventional Commits, one feature branch per change, and the PR template checklist for requirements changes.
